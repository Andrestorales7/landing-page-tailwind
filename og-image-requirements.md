# Open Graph Image Requirements for CMP Agro

To fix the blurry/squished appearance in Google search results, you need to create an Open Graph image with these specifications:

## Required Specifications:
- **Size**: 1200x630 pixels (exact dimensions)
- **Format**: PNG or JPG
- **File name**: `og-image.png`
- **Location**: `/public/favicons/og-image.png`

## Design Guidelines:
1. **High Resolution**: Use crisp, high-quality graphics
2. **Brand Colors**: Use your brand colors (the green theme from your site)
3. **Logo**: Include your CMP Agro logo prominently
4. **Text**: Keep text large and readable (minimum 24px font size)
5. **Safe Area**: Keep important content within the center 1200x600px area
6. **Background**: Use a solid or subtle gradient background

## Content Suggestions:
- CMP Agro logo
- Main tagline: "Soluciones Integrales para el Sector Agropecuario"
- Website URL: www.cmpagro.com.py
- Simple background with agricultural imagery or patterns

## Tools to Create:
- Canva (has 1200x630 templates)
- Figma
- Photoshop
- GIMP (free alternative)

## Current Status:
Your favicon configuration is now properly set up. Once you create and add the og-image.png file to /public/favicons/, the blurry/squished issue in Google search results should be resolved.
